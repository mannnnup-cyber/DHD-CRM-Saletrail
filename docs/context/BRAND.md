## Brand Migration Rule

Visible product branding may eventually become FollOps, but do **NOT** rename:

- Git repositories
- Database tables
- API routes
- Environment variables
- Supabase/Vercel projects
- Other technical identifiers

`"by Dirty Hand Designs"` may be subtle secondary attribution, not part of the primary product identity.
