## RIGHT NOW: Today's Mission (3-4 hours)

Your goal: **Have Android Studio fully installed and ready to create a project**

### Step 1: Download Android Studio (30 minutes)

Go to: https://developer.android.com/studio

**Windows:**
- Click "Download Android Studio"
- Save to Downloads folder
- Wait for download (~1 GB)

**Mac:**
- Download .dmg file
- Open and follow installer

**Linux:**
- Download .zip
- Extract and run studio.sh

### Step 2: Install Android Studio (30-45 minutes)

**Windows:**
1. Double-click installer
2. Click "Next" → Accept defaults
3. Choose installation path (default is fine)
4. Click "Install"
5. Wait... (this takes a while)
6. Click "Finish" when done
7. **DO NOT uncheck "Start Android Studio"**

**First Launch (10-15 minutes):**
1. Android Studio opens with setup wizard
2. Select "Standard" setup
3. Accept license agreements
4. Choose emulator (not needed yet, skip)
5. Let it download SDKs (this is automatic)
6. Wait for "Gradle: Build successful" message

**Android Studio is Ready When:**
- ✅ Welcome screen shows "Create a new Android Studio project"
- ✅ You can see the new project button
- ✅ Menu bar shows File, Edit, View, etc.

### Step 3: Verify Installation (30 minutes)

**Test it works:**
1. File → New → New Android Project
2. Select "Empty Activity" template
3. Project name: "TestApp"
4. Package: "com.test.myapp"
5. Click "Finish"
6. Wait for Gradle sync (~2 minutes)
7. You should see "BUILD SUCCESSFUL"

**Close test project:**
1. File → Close Project
2. Don't save when asked

**Verify SDKs:**
1. Tools → SDK Manager
2. Verify "Android 14 (API 34)" is installed ✓
3. Click "OK"
